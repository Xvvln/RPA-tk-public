# 异常模拟验证记录

验证日期：2026-07-21  
设备：Android 真机，TikTok 国际版已登录  
原则：不清数据、不退出账号、不修改权限、不主动制造账号风控。

## 真机可逆场景

| 场景 | 检测结果 | 恢复结果 |
| --- | --- | --- |
| TikTok 切到后台 | `tiktok_not_foreground` | 停止任务；手动回到 TikTok 后恢复正常 |
| TikTok 进程被停止 | `tiktok_not_foreground` | 重新启动应用后恢复正常 |
| 熄屏并进入锁屏 | `screen_off`、`device_locked` | 唤醒并解锁后恢复正常 |
| Wi-Fi 关闭、移动数据关闭、缓存视频仍可见 | `network_unavailable` | 禁止所有能力并停止；恢复 Wi-Fi 后正常 |
| 评论页显示网络不稳定 | `network_error` | 停止，不点击“重试” |
| 评论面板和键盘同时打开 | `keyboard_visible`、`comments_open` | 依次 `hide_keyboard`、`close_comments`，回到推荐页 |
| 长按视频打开中文“底部工作表” | `video_options_sheet` | `press_back`，回到推荐页 |
| 误入收件箱 | `inbox` | `navigate_home` |
| 误入个人页 | `profile` | `navigate_home` |
| 误入商城 | `shop` | `navigate_home` |
| 误入搜索页且键盘打开 | `search_input`、`keyboard_visible` | 先收键盘，再以首页按钮或返回键回推荐页 |
| UIAutomator 服务被停止 | 首次读取失败 | 自动重启服务，只重试读取，最终状态正常 |

## 合成 UI 层级场景

以下场景不能在真实账号上安全、稳定地产生，使用与 UIAutomator 相同结构的 XML
进行单元测试：

- 验证码、登录要求、频率限制、账号限制、内容不可用、强制更新和年龄确认。
- Android 权限弹窗、隐私/数据传输确认、未知系统弹窗和输入法选择框。
- 共享收藏、关注好友、关联邮箱、推广横幅、消息横幅、推荐插页及通用关闭弹窗。
- 无效 UI XML、未知页面、照片内容和空搜索结果。

账号级阻断、权限与隐私确认只验证“识别并停止”，不自动点击。输入法选择框属于已知、
可逆系统弹窗，可按返回键关闭；无法识别的系统弹窗必须交给人工。

## 未主动制造的场景

- 真实验证码、真实限流、真实封号、真实年龄/隐私确认和登录失效。
- 修改 TikTok 权限后再触发权限请求。
- 物理拔除 USB 数据线、设备断电或 Android 系统崩溃。

这些操作可能影响账号、用户设置或设备连接，不属于安全的自动化验证范围。对应检测
逻辑由合成测试覆盖，真实遇到时应停止任务、保存快照并等待人工处理。
